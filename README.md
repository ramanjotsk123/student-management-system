# Student Management System

A console-based Student Management System developed in Java.

This project demonstrates fundamental and intermediate Java programming concepts, including object-oriented programming, collections, searching, sorting, user input handling, and input validation.

## Features

- Add new students
- View all students
- Search students by ID
- Search students by name
- Sort students by grade
- Delete students
- Display the total number of students
- Validate user input
- Interactive console-based menu

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Collections
- Comparator
- Scanner
- Exception Handling
